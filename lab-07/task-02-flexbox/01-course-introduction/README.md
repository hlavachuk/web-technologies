# 01. Introduction to What The FlexBox

Вступ до курсу. Flexbox розв’язує задачі одновимірної розкладки: вирівнювання, розподілу місця та адаптивного перенесення елементів. Перший урок оглядовий; цей приклад демонструє результат.

## Реалізація

```css
.demo{display:flex;gap:var(--gap)}.box{flex:1}
```

Відкрити `index.html`. HTML і CSS можна змінювати без збірки. Приклад адаптовано за темою оригінального уроку, із власною розміткою та оформленням.
