# 02. Introduction to Flexbox

display:flex створює flex-контейнер. Його безпосередні дочірні елементи стають flex-елементами. Порівняй зі звичайними блоками, прибравши display:flex.

## Реалізація

```css
.demo{display:flex;min-height:250px}.box{flex:1}
```

Відкрити `index.html`. HTML і CSS можна змінювати без збірки. Приклад адаптовано за темою оригінального уроку, із власною розміткою та оформленням.
