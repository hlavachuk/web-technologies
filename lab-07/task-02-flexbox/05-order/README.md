# 05. Flexbox Ordering

order змінює лише візуальний порядок. Елементи з меншим значенням йдуть першими. Порядок читання та навігації Tab може відрізнятися, тому змістовний порядок задавай у HTML.

## Реалізація

```css
.demo{display:flex;flex-wrap:wrap}.box{flex:1}.box:nth-child(3){order:1}.box:nth-child(5){order:2}
```

Відкрити `index.html`. HTML і CSS можна змінювати без збірки. Приклад адаптовано за темою оригінального уроку, із власною розміткою та оформленням.
