# 03. Working with Flexbox flex-direction

flex-direction визначає головну вісь. row — рядок, column — стовпець; суфікс reverse змінює напрямок. DOM-порядок залишається тим самим.

## Реалізація

```css
.demo{display:flex;flex-direction:column-reverse;min-height:320px}.box{flex:1}
```

Відкрити `index.html`. HTML і CSS можна змінювати без збірки. Приклад адаптовано за темою оригінального уроку, із власною розміткою та оформленням.
